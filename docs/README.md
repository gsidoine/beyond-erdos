# Searchable Meta Erdős catalogue

`index.html` is a responsive, local-searchable browser for the **25 current research entries**.

The canonical data lives in [`../data/problems.json`](../data/problems.json); `problems.json` here is generated by `python scripts/generate_catalog.py`.

To publish the browser, enable GitHub Pages with **Deploy from a branch → main → /docs**, after the corresponding PR has been merged. Then the expected Pages URL is `https://gsidoine.github.io/meta-erdos/`. The site is a static frontend for the same canonical data; availability depends on the repository's Pages configuration. The browser works locally if served over HTTP (for example, `python -m http.server 8000` from `docs/`) because browsers typically block `fetch` from `file://`.

All individual dossier links open the canonical GitHub Markdown files. The UI is dependency-free and does not use an external search service.
