# Searchable Beyond Erdős catalogue

\`index.html\` is a responsive, local-searchable browser for the **ten existing candidates**.

The canonical data lives in [\`../data/problems.json\`](../data/problems.json); \`problems.json\` here is generated by \`python scripts/generate_catalog.py\`.

To publish the browser, enable GitHub Pages with **Deploy from a branch → main → /docs**, after the corresponding PR has been merged. Then the expected Pages URL is \`https://gsidoine.github.io/beyond-erdos/\`. This URL is **not claimed live until Pages has been enabled**. The browser works locally if served over HTTP (for example, \`python -m http.server 8000\` from \`docs/\`) because browsers typically block \`fetch\` from \`file://\`.

All individual dossier links open the canonical GitHub Markdown files. The UI is dependency-free and does not use an external search service.
