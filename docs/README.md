# Searchable Meta Erdős catalogue

The browser displays **12 Acorns, 23 Seedbed questions and one resolved Harvest result** (**36 current research entries**).

Collection membership comes from [the canonical curation index](../data/curation.json), mirrored to `curation.json`. Research metadata comes from [the canonical problem index](../data/problems.json), mirrored to `problems.json`. Both mirrors are regenerated by `python scripts/generate_catalog.py`.

The browser filters by field, research status, priority and collection. Individual entries link to their canonical GitHub dossiers. Source reviews remain in the repository's audit directories.

GitHub Pages may be enabled from `main` under `/docs`. To test locally, serve `docs/` over HTTP; direct `file://` access can block data loading.
