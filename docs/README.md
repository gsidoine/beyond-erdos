# Problem catalogue

The searchable catalogue comprises **41 current research entries**: 13 Acorns, 27 Seedbed questions and 1 Harvest result.

The canonical records are [`data/problems.json`](../data/problems.json) and [`data/curation.json`](../data/curation.json). Their derived copies in this directory are regenerated by `python scripts/generate_catalog.py`.

The [browser](index.html) provides search and filtering by subject, mathematical status and editorial collection. Individual records link to the corresponding mathematical dossiers.

The [P001–P030 consolidation](../audits/portfolio-consolidation-P001-P030.md) is a historical assessment, not the current allocation. GitHub Pages may serve this directory from `main`; for local viewing, serve `docs/` over HTTP.
