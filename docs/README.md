# Problem catalogue

The searchable catalogue comprises **42 current research entries**: 13 Acorns, 28 Seedbed questions and 1 Harvest result.

The canonical records are [`data/problems.json`](../data/problems.json) and [`data/curation.json`](../data/curation.json). Their derived copies in this directory are regenerated by `python scripts/generate_catalog.py`.

The [published browser](https://gsidoine.github.io/meta-erdos/) (source: [index.html](index.html)) provides search and filtering by subject, mathematical status and editorial collection. Individual records link to the corresponding mathematical dossiers.

The [P001–P041 literature comparison](../audits/literature-comparison-P001-P041.md) records nearest sources and unresolved priority distinctions. The [P001–P030 consolidation](../audits/portfolio-consolidation-P001-P030.md) is a historical assessment, not the current allocation. GitHub Pages may serve this directory from `main`; for local viewing, serve `docs/` over HTTP.

Repository: https://github.com/gsidoine/meta-erdos.
